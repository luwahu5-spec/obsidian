# .NET and Node Security Audit — core-web and core-web-api

As of 2026-10-28.

**Takeaway:** Both solutions target .NET 8. But the core-web pipeline still builds with **Node 16** and an old SDK image (**8.0.417**), the Lambda deploy configs still say **.NET 6**, and **jsPDF 2.5.1** (shipped to browsers) has critical advisories. **.NET 8 support ends on 2026-11-10**, so plan the move to .NET 10 LTS.

## Upgrade targets

| Component | Latest secure version | Notes |
|---|---|---|
| .NET 8 runtime / SDK | **8.0.33 / 8.0.427** (25 Oct 2026, out of band) | End of support 2026-11-10 |
| .NET 10 LTS runtime / SDK | **10.0.14 / 10.0.403** | Supported until 2028-11-14 |
| Node.js 24 LTS | **24.22.1** (21 Oct 2026) | Other fixed lines: 22.23.4, 26.12.1 |
| jsPDF | **4.2.1** | Major version jump: retest PDF export |

**Elastic Beanstalk:** not confirmed. The `s3user-staging` user sees no Elastic Beanstalk applications or environments in ap-southeast-2, and has no access to EC2 or ECS. Someone with production AWS access needs to check the environment's platform version (EB console → Environment → Platform) or run `dotnet --list-runtimes` on the host.

### Latest .NET 8 security releases

- **8.0.33 (25 Oct 2026)**:
  - CVE-2026-111497: Brotli decoder out-of-bounds write (DoS, info disclosure, privilege escalation).
  - CVE-2026-70197: `SocketAsyncEventArgs` memory corruption (re-release, because 8.0.32 didn't fully fix it).
  - CVE-2026-114148: wrong file ownership in Linux tarballs.
- **8.0.32 (13 Oct 2026)**: 42 CVEs.
  - ASP.NET Core: remote code execution (CVE-2026-96230), privilege escalation, security-feature bypass, DoS.
  - Runtime: several remote code execution issues.
  - SDK: remote code execution (CVE-2026-96237).
  - QUIC: remote code execution (CVE-2026-105016).
- **Affected:** every 8.0.x below 8.0.33. 10.0.x below 10.0.14 is affected the same way.

## Node and npm (core-web only, build-time)

Node only builds the frontend bundle (`Minnovare.Core.Web.csproj:105` runs `npm run build` with rollup). Nothing runs on Node in production, but the bundled packages do ship to users' browsers.

| What | We use | Status | Upgrade to |
|---|---|---|---|
| **core-web pipeline** (`bitbucket-pipelines.yml:20`) | **Node 16** (`setup_16.x`) | Unsupported since Sep 2023 | Node 24 LTS (24.22.1) |
| Dev machine | Node 24.13.1 | Affected by the 21 Oct release | 24.22.1 |
| **jspdf** | 2.5.1 | **Critical**: arbitrary JS execution via PDF injection, path traversal, DoS | 4.2.1 |
| dompurify (comes in through jspdf) | ≤ 3.4.16 | **Critical**: XSS | Updated by the jspdf upgrade or `npm audit fix` |
| fflate | 0.4.x | Moderate: infinite loop on bad ZIP64 | `npm audit fix` |
| chart.js 3.9.1, date-fns 2.29.3, tippy.js 6.3.7, jszip 3.10.1, file-saver 2.0.5 | — | No advisories. chart.js and date-fns are a major version behind | Optional |
| Build tools (rollup plugins, eslint 7.32, postcss 8.4.21, sass 1.60) | — | About 20 high findings, build-only | Bump when convenient |

**21 Oct 2026 Node release (22.x / 24.x / 26.x):**
- High: Brotli out-of-bounds write in `node:zlib` (CVE-2026-111497, same CVE as .NET), TLS hostname bypasses via unusual IPv4 spellings (CVE-2026-105483, CVE-2026-106069), `dns` NUL-byte truncation (CVE-2026-105482).
- Medium: keep-alive response smuggling, repeated `randomUUID` values in snapshots, DNS SANs matching IP endpoints.
- Low: Permission Model bypasses.

1. core-web pipeline: Node 16 → 24, and SDK image 8.0.417 → 8.0.
